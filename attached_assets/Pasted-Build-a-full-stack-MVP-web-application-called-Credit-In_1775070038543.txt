The goal of the application is to aggregate financial news related to credit markets and transform it into structured, actionable insights.

TECH STACK REQUIREMENTS:

Backend: Python (FastAPI preferred)
Frontend: Simple React or lightweight HTML/CSS (keep clean and minimal)
Database: SQLite (for MVP simplicity)
Use OpenAI API for summarization and analysis
Use free news APIs (e.g., NewsAPI or RSS feeds)

NewsAPI (focus on keywords like "credit markets", "leveraged loans", "high yield bonds", "downgrades", "defaults")

title
source
publish date
URL
raw content

A concise summary (3–5 sentences)

Sector (e.g., Retail, Tech, Energy)
Event type (downgrade, earnings, default risk, refinancing, M&A, macro)
Sentiment (positive, negative, neutral for credit)
"Why This Matters" section:
Explain implications for:
credit risk
bond spreads
CLO portfolios (if relevant)
"Who Cares":
Tag relevant users:
Credit Analysts
Traders
Portfolio Managers
CLO Managers

Store all AI outputs in the database.
